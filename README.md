# layahilarius.github.io

My portfolio: things I built, product case studies and short videos of me answering product questions.

Live at https://layahilarius.github.io/

- All text lives in `src/content.ts`. Edit that file to change what the site says.
- Every push to `main` deploys through GitHub Actions (Settings → Pages → Source: GitHub Actions).
- Run locally: `npm install`, then `npm run dev`.
